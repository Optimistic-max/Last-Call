# README illustrations: prompts

The five pictures in this folder were drawn in code from the descriptions below, not made with an image tool: open [`drawings.html`](drawings.html) in a browser (`#1` to `#5` picks the picture) and take a 1600x900 screenshot to make the PNG again after a change. The prompts stay here as the description of each picture, and still work with an image tool if the team ever wants one.

Style: the [Ian Xiaohei Illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations) skill (MIT, by Ian; credit kept in the README). Its prompt template, with the labels changed from Chinese to English for an English README.

To use an image tool instead, generate each image on its own (one image per request) at 16:9, about 1600x900, as a PNG, and save it here under the file name shown. Each image explains one idea. Check each one against the skill's `references/qa-checklist.md` and regenerate if Xiaohei is only decoration, the picture is crowded, it looks like a slide, a label is misspelled, or there's a title in the top-left corner.

Honesty rule (AGENTS.md 17): no real logos, no real people, no fake numbers presented as real. The PayPal word may appear as a hand-written label only, never the PayPal logo.

## Shared style block (paste at the top of every prompt)

```text
Generate one standalone 16:9 horizontal article illustration.

Visual DNA:
Pure white background. Minimalist black hand-drawn line art. Slightly wobbly pen lines. Lots of empty white space. Sparse red/orange/blue handwritten English annotations in a casual pen script. Clean absurd product-sketch feeling. No gradients, no shadows, no paper texture, no complex background, no commercial vector style, no PPT infographic look, no cute mascot poster, no children's illustration, no realistic UI, no logos.

Recurring character required:
Xiaohei, a small solid-black absurd creature with white dot eyes, tiny thin legs, blank serious expression, slightly uneven hand-drawn body shape. Xiaohei must perform the core conceptual action, not decorate the scene. Serious, deadpan, slightly bizarre, not cute.

Color use:
Black for line art and Xiaohei. Orange for the main flow, path and arrows. Red only for the key warning or result. Blue only for secondary notes.

Constraints:
One image explains one idea. Main subject 40 to 60 percent of the canvas, at least 35 percent white space. At most 5 short handwritten English labels, spelled exactly as given. No title in the top-left corner. Not a formal diagram or slide. Clear but not instructional, strange but clean.
```

## 01-hold-not-charge.png (README top)

```text
Theme: Last Call, a group payment app where nobody pays unless the goal is reached.
Core idea: a pledge is a hold, not a charge. The money is set aside but not taken.
Composition: Xiaohei stands on tiptoe sealing a lid onto a clear glass jar that holds a few banknotes and a tiny card. Behind it, a cash register sits closed with a small padlock on its drawer. A thin orange dotted line runs from the jar toward the register and stops halfway at a hand-drawn gate that is shut.
Labels: "up to $40" (on the jar) / "held, not charged" (orange, by the lid) / "goal: $300" (blue, on the gate) / "nobody pays unless..." (red, under the register)
```

## 02-goal-reached.png ("How it works", step 2)

```text
Theme: the goal is reached, so everyone pays once, and only their fair share.
Core idea: every hold pays a small, equal-feeling share at the same moment; the rest stays with its owner.
Composition: four clear jars in a row, each with a different amount inside. Xiaohei stands on a little ladder above them pulling one long lever, which tips all four jars a little at the same time. A thin trickle pours from each jar into one shared pot labeled with the goal. Most of each jar's money stays inside. A small stopwatch hangs from the lever.
Labels: "last call" (orange, by the stopwatch) / "charged once" (red, by the pot) / "only your share" (orange, by one trickle) / "rest released" (blue, by a jar)
```

## 03-goal-missed.png ("How it works", step 3)

```text
Theme: the goal is missed, so every hold is cancelled and nobody pays.
Core idea: nothing was taken, so everything goes back untouched.
Composition: a shared pot with a short line marking the goal, the money level well below it. A wilted little flag on the pot. Xiaohei walks along a row of jars, calmly unscrewing each lid and handing a banknote back to a plain stick-figure hand that reaches in from the edge of the frame.
Labels: "goal missed" (red, by the pot) / "hold cancelled" (orange, by a lid) / "nobody pays" (blue)
```

## 04-ai-reads-you-confirm.png ("How the AI is used")

```text
Theme: the AI only reads a friend's message; the friend confirms; plain code does the money.
Core idea: three hands, three jobs, in order. The AI suggests, the person decides, the calculator counts.
Composition: left, a chat bubble on a string that says "down if Jay goes, max 40". Middle, Xiaohei wearing tiny round reading glasses holds a magnifying glass over the bubble and writes on an index card. The card is passed to a stick-figure hand that ticks a box on it. Right, a plain old desk calculator, and only the ticked card is allowed through a small slot into it. An orange arrow runs bubble to card to tick to calculator.
Labels: "AI reads" (orange, by Xiaohei) / "you confirm" (blue, by the tick) / "code does the money" (red, by the calculator) / "max $40, only if Jay's in" (on the card)
```

## 05-save-before-you-send.png ("How PayPal is used")

```text
Theme: save before you send. Every payment request gets a ticket number that is written down first, so a retry can't charge twice.
Core idea: the same ticket twice is recognized as the same request.
Composition: Xiaohei at a small desk writes a ticket number into a thick notebook, then pushes the same paper ticket through a little bank-teller window labeled with a hand-written word. A second, identical ticket is coming through behind it, and a hand behind the window holds up a stamp that says "same ticket".
Labels: "1. write it down" (orange, by the notebook) / "2. then send" (orange, by the window) / "PayPal" (black handwriting on the window sign, no logo) / "same ticket = no double charge" (red)
```
